Architecture (confirmed via static sweep of refs\thinker + Ghidra decompiles; symbols in terranx.h + Ghidra):
- The HUD strip is the **non-client area of the fullscreen map window** `MapWin_g` (Console) @0x9156B0 — not a separate window. `Console_init` @0x51D890; map client H = ScreenH − strip height.
- **`g_console_strip_height` @0x7AF59C = the keystone** (219 native; static 0, runtime writer TBD). Read by Popup_show / BaseWin_init / FileDlg_layout — every modal's "black lower portion" reserves HUD space through it, so scaling it ×g/16 propagates to modal placement.
- The ENGINE centers the fixed 1024-wide strip when ScreenWidth>1024 (thinker ConsoleWidth=1024 / ConsoleHeight=219; PRACX only mirrors this in edge-scroll — it does NOT position the HUD).
- Strip art = NC sprites (iface.pcx / interface.pcx) extracted in `load_interface` @0x455610 → `GraphicWin_set_def_nc_sprites`; panel geometry globals are SUMS of sprite dims computed there → scaling the sprites at load makes derived geometry follow.
- Left panel = StatusWin_g @0x8C5568; strip mouse input = Console_on_nc_hittest/left_down/left_up/mouse_move @0x50F680/0x50FB10/0x50FE70/0x510110 (any draw-time scale needs inverse coord transform here); readouts Console_update_data @0x514880.
- Chat lines above HUD = `NetMsg_g` ticker @0x805338 (`NetMsg_pop` @0x47A890) — SHARED with SP notifications. Time-control widget: `Console_time_controls` @0x515900, label = TimeControl_table[0].name @0x94F1B8.
