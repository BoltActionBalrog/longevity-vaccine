## Debug lessons (reusable)
- **The garbage value IS the diagnosis**: 107374180·20 = 0x7FFFFFD0 ⇒ dividend ≈ small NEGATIVE as unsigned; decoded to (u32)(−64)/40 before finding the code. All `x*16/g` back-computes in frame thunks use unsigned DIV — any future degenerate rect would have crashed the same way ([[feedback-negative-height-saved-copy]] class).
- Buffer_init fatal branch = 0x5D7798; error string 0x696c20 xref'd ONLY there. `Buffer_init` rejects NEGATIVE w/h gracefully (ret 3) but w=0/huge → CreateDIBSection NULL → FATAL. Never "fix" a degenerate rect by clamping to 0.
- hook_mp_bufinit.js pattern: log every Buffer_init + attach at the FATAL branch → last-logged call = culprit; add raw-stack scan (x86 backtracers unreliable) + dump Dialog fields via the vtable adjustor `D = this + *(*(this)+8)`.
- `run-frida-at-res.bat` logs OVERWRITE by default — repoint shortcuts with `-Pre frida_log_append.js` BEFORE multi-res runs or the first run's log is lost.
