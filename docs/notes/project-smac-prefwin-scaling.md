## Reusable patterns (proven here, portable)

- **Vtable-slot repoint → gated flag-arm stub**: to run an existing gated machine (popup 2D-zoom via `g_popup_active`, netwin nub scale via `g_netwin_active`) for ONE widget class's specific instances, repoint the class vtable slot (a 4-byte DATA patch, e.g. [0x669784] = FlatButton vtbl+0x30 content-draw, [0x669D88] = ScrollBar_draw) to a stub that compares ecx against the instance statics, sets the flag around a call to the real entry, else plain-jmps. Zero code-site patches, byte-neutral for every other instance. Works because widget instances are STATICS in this engine.
- **GraphicWin_init entry-gate**: one entry detour on the shared ctor scales a whole window family — gate (A) ecx==the window static → window-position law, (B) parent arg==the window → children ×g/16, (C) parent∈{sub-widget statics} → grandchildren. Exempt paths that own their own law by RETURN-ADDRESS RANGE (here [0x60E800,0x60F000) = the page-attach path that thunk_list_fill_width owns). Grandchild ctor args may be derived from ALREADY-SCALED parent fields — gate each arg on native plausibility (slider right-arrow x=800 was parentW−20, already scaled; x,y≤340 / w,h≤40 scaled, else left).
- **Show-time font+redraw fix**: widgets that seed their font slot from a native default at BUILD time (btn+0x970) can't be fixed at build without touching the shared default — instead, at the window's show entry: `find_font(scaled)` → write the slots → drive vtbl+0xF8 refresh of every widget. Idempotent, runs every show.
- **Native-expression window law**: PrefWin's ctor computes x=SW/2−350, y=SH−618 itself (screen terms resolution-dependent, constants not) → the law scales ONLY the constants: x=SW/2−fl(350g/16). The g=16 no-op is algebraic.

- ⚠ **Three new baked entry detours** (push/ret): GraphicWin_init 0x5D4EF0, FUN_0060e800, PrefWin_show 0x48FA00 — these entries AND every call site into them are now Frida-untouchable ([[feedback-frida-attach-branch-target]] #5/#7).
